# Dr. Omar's Science World: Racing demo

Live site: https://dynamic-kashata-ec4dd6.netlify.app (teacher room: `/teacher.html`). Netlify redeploys on every push to `master`.

Browser racing game where correct science answers move your car up the field.
Built from `Science_World_Complete_Handoff.md` (v1.0, 30 Oct 2026).

## Run locally

```bash
node tools/serve.mjs 5173   # then open http://localhost:5173
npm test                    # race-rule tests (node --test)
```

No build step. Three.js 0.160.0 and supabase-js 2.45.4 load from jsDelivr.
Pages: `index.html` (students and guests), `teacher.html` (teacher room).

## Supabase setup (once)

1. Supabase → SQL Editor → paste `supabase/schema.sql` → Run (safe to re-run).
2. Authentication → Sign In / Providers → Email → turn off **Confirm email** (students log in with usernames).
3. Sign up on the game page with your teacher username, then run in the SQL Editor:
   `update public.profiles set role = 'teacher', status = 'approved' where username = 'your-username';`
4. Log in at `/teacher.html`.

Database rule tests (needs a local Postgres): apply `supabase/schema.sql` to a scratch database with
a stub `auth` schema, then run `supabase/tests/rules_test.sql`.

## Files

- `js/race-engine.js`: race rules only (positions, retries, first-to-10 finish, rewards, duplicate-request safety). Will move server-side for multiplayer.
- `js/race-scene.js`: Three.js circuit, scenery, cars, chase camera, minimap, graphics settings.
- `js/main.js`: screens, question UI, Free Drive timer, Solo bots, input (keyboard / touch / gamepad).
- `js/config.js`: every tunable number; open decisions are marked PROVISIONAL.
- `js/questions.js`: **sample** 10-question set used for guest races (synthetic, not teacher-approved).
- `js/supabase.js`: Supabase client and API calls. The publishable key is public by design.
- `js/teacher.js`, `css/teacher.css`: teacher room (approve students, import / preview / release sets).
- `js/import-sets.js`: CSV/JSON question-file parser with validation. Sample: `samples/plant-season-set.csv`.
- `supabase/schema.sql`: tables, row level security, and the functions that judge answers and write rewards.
- `assets/car.json`: low-poly car as embedded glTF (748 triangles), generated by `tools/make_car.py`.
- `tools/make_car.py`: Blender script: `blender -b --factory-startup -P tools/make_car.py -- car.glb`, then `node tools/glb_to_json.mjs car.glb assets/car.json` (the artifact host does not serve .glb).

## Rules implemented (Stage 1)

| Handoff rule | Behavior | Verified by |
| --- | --- | --- |
| R01 first to 10 correct ends the race for everyone | Engine freezes all answers at the finish | test + browser run |
| R02 correct → overtake one place, wrong → drop one place, retry same question | Swap with neighbour; animated pass | tests + browser |
| R03 15 s Free Drive after a correct answer, steering cannot change rank | Lateral steering only; rank comes from the engine | browser |
| R05 untimed answering | No question timer | — |
| E01 100 first attempt / 100 first correct / 500 participation / 200 winner (Friends & Teacher only) | `RaceEngine.rewards()` | tests (2,700 winner example) |
| AC16 duplicate request applied once | requestId map | test |
| C01 no copy/paste/context menu on question panel only | event blockers on `#qpanel` | manual |
| V02 graphics + frame-rate settings with real effect | pixel ratio, shadows, scenery density, fog distance, 30/60 cap | manual |
| A04 portrait touch devices see a rotate prompt | CSS orientation query | manual |
| Section 04 simulated rivals never pose as classmates | "BOT" tag on every bot | browser |

## Provisional choices (open in handoff Section 17)

- O02: player starts last; first place and last place hold on correct/wrong; positions are unique (no shared places yet).
- O03: the race ends on the 10th correct answer even if the car is not displayed in 1st.
- Results ranking below the winner: by correct answers, ties share a rank.
- Bot pace/accuracy are demo tuning only.

## Stage 2 rules (database-enforced)

- New sign-ups are pending until a teacher approves; nobody can make themselves a teacher.
- Students never receive answer keys: questions come from `start_race` without answers, and `submit_answer` judges each one.
- Hidden (unreleased) sets cannot be started, even by direct call (AC06).
- O-Bucks are an append-only ledger with unique event keys: duplicate requests and replays add nothing (AC16, AC19).
- PROVISIONAL (O04): first-attempt/correct rewards are once per student per question per set; the 500 participation bonus is once per student per set per mode, and needs ≥ 1 answer and ≥ 60 s of racing.
- Students cannot read other students' profiles, races or balances, or write to the ledger.

## Known gaps

- No store, Collection, Stats, season map or parent accounts yet. Guest races save nothing.
- Controller remapping not built (basic gamepad: left stick steers, A/B/X/Y answer).
- Performance not measured on real phones/iPads yet; Low quality is the default on touch devices.
